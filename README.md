# Telegram Task Bot

Простой Telegram-бот для командной работы с общим списком задач. Задачи хранятся в SQLite-базе `tasks.db`.

## Возможности

- `/start` — приветствие и список команд
- `/add <текст задачи>` — добавить задачу в общий список
- `/add` — добавить задачу пошагово: бот спросит текст следующим сообщением
- `/edit` — изменить задачу: бот покажет список с кнопками, выберите нужную и введите новый текст
- `/cancel` — отменить пошаговый ввод или изменение
- `/list` — показать все задачи вместе с полной историей правок (при большом количестве список будет разбит на несколько сообщений)
- `/list_csv` — получить задачи в CSV-файле, включая историю правок

Изменять задачи может любой пользователь. Дата и автор каждой правки сохраняются прямо в задаче; дата создания и автор исходной задачи не меняются.

## Установка и запуск

1. Перейдите в папку проекта:

   ```bash
   cd telegram_task_bot
   ```

2. Создайте и активируйте виртуальное окружение:

   **Windows (PowerShell):**

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   **Linux/macOS:**

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Задайте токен бота, полученный у [@BotFather](https://t.me/BotFather).

   Создайте файл `.env` на основе `.env.example`:

   ```env
   BOT_TOKEN=ВАШ_ТОКЕН
   ```

   Если для доступа к Telegram API нужен прокси, добавьте в `.env`:

   ```env
   PROXY_URL=socks5://127.0.0.1:10808
   ```

   Без `PROXY_URL` бот подключается к Telegram напрямую. Вместо файла `.env` можно использовать переменные окружения:

   **PowerShell:**

   ```powershell
   $env:BOT_TOKEN="ВАШ_ТОКЕН"
   $env:PROXY_URL="socks5://127.0.0.1:10808"
   ```

   **CMD:**

   ```cmd
   set BOT_TOKEN=ВАШ_ТОКЕН
   set PROXY_URL=socks5://127.0.0.1:10808
   ```

   **Linux/macOS:**

   ```bash
   export BOT_TOKEN="ВАШ_ТОКЕН"
   export PROXY_URL="socks5://127.0.0.1:10808"
   ```

5. Запустите бота:

   ```bash
   python main.py
   ```

## База данных

Бот использует SQLite3. Файл базы данных `tasks.db` создаётся автоматически в папке проекта при первом запуске.

Таблица `tasks`:

| Поле       | Тип     | Описание                                        |
|------------|---------|-------------------------------------------------|
| id         | INTEGER | Уникальный ID задачи                            |
| text       | TEXT    | Текст задачи                                    |
| user       | TEXT    | Имя автора задачи                               |
| created_at | TEXT    | Дата и время создания                           |
| updated_at | TEXT    | Дата последней правки (NULL, если не менялась)  |
| updated_by | TEXT    | Кто изменил задачу последним (NULL до правки)   |
| history    | TEXT    | Полная история правок в формате JSON           |

История хранится прямо в строке задачи в колонке `history` — отдельной таблицы для неё нет. Каждая правка добавляет запись с датой, автором, старым и новым текстом. Команды `/list` и `/list_csv` выводят историю полностью.

При первом запуске `init_db()` автоматически добавит недостающие колонки в уже существующую базу старой версии. Если база была создана предыдущей версией бота с отдельной таблицей `task_edits`, её записи переносятся в колонку `history`, после чего старая таблица удаляется.

Файл `tasks.db` и файл `.env` с токеном добавлены в `.gitignore` и не должны попадать в репозиторий.
